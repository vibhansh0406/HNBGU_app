CampusOne brand assets

Files:
- campusone-c-mark.svg: transparent-background vector trace of the supplied C mark.
- campusone-app-icon.svg: white rounded-square icon composition.

Important:
These SVGs are traced from the supplied raster reference, not the original editable vector source.
The mark silhouette is preserved as closely as possible, but JPEG edge compression can introduce tiny contour differences.
Before production release, compare at 100% against the original and approve the vector master.
Do not alter proportions, reshape corners, or add effects.
For Android adaptive icons, use the C mark as foreground and create the background as a separate Android resource;
do not simply use the complete rounded-square SVG as the adaptive foreground.
