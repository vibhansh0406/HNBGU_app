# CampusOne — On-Device Edition (`com.campusone.app`)

100% On-Device Android project for Indian college students (pilot: HNB Garhwal University).
Built with Kotlin 2.0.20, Jetpack Compose Material 3, Room 2.6.1, WorkManager 2.9.1, DataStore 1.1.1, and Manual DI (`AppContainer`).

## Build Command (GitHub Actions / Codespaces)
Run `gradle testDebugUnitTest assembleDebug` inside the `CampusOne` directory with JDK 17 and Gradle 8.9.
